Direct synchronization bridge between ForgeStudio SaaS and your WordPress website.

== Description ==

ForgeStudio Connector seamlessly receives visual pages created in ForgeStudio and publishes them natively to your WordPress site.

Features:
* REST API Handshake with token authentication
* High-performance static HTML/CSS injection with Gutenberg block fallbacks
* Native Elementor Pro schema integration
* Yoast SEO and RankMath meta tag synchronization
* Automatic mobile responsive stylesheets
